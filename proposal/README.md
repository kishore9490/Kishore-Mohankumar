# Infinitia Links — Enterprise Digital Identity Proposal

General commercial proposal for **Infinitia Links** (a product of **Infinitia Hub**) — a centralised digital identity, verification and workforce information platform.

## Deliverables

| File | Description |
|---|---|
| `Infinitia_Links_Enterprise_Digital_Identity_Presentation.pptx` | 25-slide 16:9 deck with speaker notes, built on a theme and layouts so it can be restyled and edited in PowerPoint |
| `Infinitia_Links_Enterprise_Digital_Identity_Proposal.pdf` | 25-page A4 business & technical proposal |
| `visual-assets/` | Every original visual used in both documents (high-resolution PNG, transparent where relevant) |
| `visual-assets/brand/` | Official logos as supplied, plus transparent and white-text variants derived from them |

Editable placeholders to complete before sending: **prices** (`₹[To be quoted]`), **contact name / email / phone** (`[To be added]`), and **Prepared for: [Organisation name]** on the PDF cover.

## Content rules followed

- All people, organisations, IDs and figures are **fictional** and marked **DEMO**. Demo QR codes encode `DEMO-ONLY https://verify.example/demo/…` (a reserved example domain), not live links.
- Capabilities are labelled **Core**, **Configurable**, **Optional** (separately scoped) or **Roadmap**.
- No certification, customer, testimonial or savings claims. Prices are placeholders only.
- Not specific to any single university; no RGUHS references.

## Rebuilding

Requires Node 18+, Chromium/Playwright and the pptx skill's `apply_theme.js`.

```bash
cd source
npm install                      # pptxgenjs, sharp
node render-assets.js            # mockups/mockups.html  -> ../visual-assets/*.png
node build-embeds.js             # web-sized copies + brand-coloured icons -> build/
NODE_PATH=$PWD/node_modules PPTX_SKILL=<path-to-pptx-skill> node build-deck.js
node build-pdf.js                # pdf/proposal.html -> ../…Proposal.pdf
```

The slide backgrounds (`source/build/bg-*.png`) are generated by a short Python/Pillow snippet. They are committed so the build works without it.
